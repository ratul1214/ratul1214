# Setup Guide — Snake, Wakatime & Spotify

You'll need three things to get the new widgets working. Each takes 2–5 minutes.

---

## 🐍 1. Snake animation

The snake SVG is generated by a GitHub Action that runs on a schedule and pushes the result to an `output` branch.

**Steps:**
1. In your `ratul1214/ratul1214` repo, create the folder `.github/workflows/`
2. Drop `snake.yml` into it
3. Go to **Settings → Actions → General → Workflow permissions** → enable **"Read and write permissions"**
4. Go to the **Actions** tab → click **Generate Snake Animation** → click **Run workflow** to trigger the first build
5. Wait 1–2 minutes. The action creates an `output` branch with the SVG files the README already points to.

No secrets needed.

---

## ⏱️ 2. Wakatime stats

Wakatime tracks coding time from your editor (VS Code, JetBrains, Vim, etc.).

**Steps:**
1. Sign up at [wakatime.com](https://wakatime.com) and install the plugin in your editor
2. Grab your API key from [wakatime.com/api-key](https://wakatime.com/settings/account)
3. In your `ratul1214/ratul1214` repo, go to **Settings → Secrets and variables → Actions → New repository secret**:
   - `WAKATIME_API_KEY` → your Wakatime key
   - `GH_TOKEN` → a [personal access token](https://github.com/settings/tokens) with `repo` scope (classic token works)
4. Drop `waka.yml` into `.github/workflows/`
5. Run it once manually from the **Actions** tab

The action will replace the `<!--START_SECTION:waka-->` block in your README with stats every Monday.

> **Note:** Stats only appear after you've coded with Wakatime tracking active for a few days. Empty until then.

---

## 🎧 3. Spotify now-playing

This uses [spotify-github-profile.kittinanx.com](https://spotify-github-profile.kittinanx.com), a free service.

**Steps:**
1. Go to [spotify-github-profile.kittinanx.com](https://spotify-github-profile.kittinanx.com)
2. Click **Login with Spotify** and authorize
3. Copy the `uid` from the URL it gives you
4. In your README, replace **both** instances of `YOUR_SPOTIFY_UID` with that value
5. Commit — done.

If you'd rather skip Spotify, just delete the "Currently Listening On Spotify" section from the README.
